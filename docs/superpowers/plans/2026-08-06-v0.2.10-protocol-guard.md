# V0.2.10 Protocol Guard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent tool-protocol markup from external evidence or malformed final model responses from leaking to Claude Code, while keeping short pass-through managed requests free of an unnecessary visible progress block.

**Architecture:** Add protocol inventory and recursive neutralization at the managed-tool boundary, inspect every managed final response, and perform at most one tool-disabled repair round when the final response violates the contract. Defer the first visible managed progress state until a real tool call, media work, queue state, or the semantic heartbeat threshold.

**Tech Stack:** Node.js 22, Anthropic Messages API compatibility, Server-Sent Events, node:test.

## Global Constraints

- Preserve transparent bypass behavior for plain Anthropic requests.
- Do not log prompt text, fetched page content, API keys, authorization headers, Base64, or full local paths.
- Do not execute or interpret control tags found in external evidence.
- Perform at most one final-response repair round.
- Keep existing managed-tool round limits independent from the repair round.
- Use TDD for every production change.
