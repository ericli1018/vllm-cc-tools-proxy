# V0.2.15 Proxy-Turn Progress Semantics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Replace ambiguous task-completion progress text with response-aware proxy-turn states without changing execution behavior.

**Architecture:** Add a pure Anthropic response progress classifier, pass its phase and details through `ProgressStream.closeProgress`, and select streaming messages from the first upstream block type. Update generic and media heartbeats to refer to the current model request.

**Tech Stack:** Node.js 22, ECMAScript modules, Node test runner, Anthropic SSE.

- Preserve V0.2.14 Tool Routing and Recovery Routing exactly.
- Do not add environment variables.
- Never claim the complete Claude Code task is finished.
- Keep fast requests free from a progress block when the visibility threshold was not crossed.
