# V0.2.25.1 Managed Streaming Hotfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every Managed Base Model round use Anthropic SSE streaming so upstream byte counters and stall detection observe live response activity while preserving the existing Managed Loop JSON response contract.

**Architecture:** Replace only the Managed Loop upstream adapter (`callUpstreamJson`) with a streaming adapter that requests `stream:true`, counts raw response chunks through the existing Base Upstream callback, and reconstructs one Anthropic Message object from SSE events. Keep the Managed Loop, WebSearch Fast Lane, Large-context Gate, WebFetch/Ollama routing, language policy, and Claude Code-visible SSE lifecycle unchanged.

**Tech Stack:** Node.js 22 ESM, Anthropic Messages SSE, node:test.

## Global Constraints

- External runtime version: `0.2.25.1`.
- npm metadata version: `0.2.25+hotfix.1`.
- No new ENV variables.
- Managed Base Model requests must use `stream:true`.
- Raw Base vLLM HTTP response chunks must continue updating `receivedBytes` and `lastByteAt`.
- Managed Loop must continue receiving a complete Anthropic Message JSON object.
- Existing v0.2.25 Fast Lane, Large-context Gate, WebFetch/Ollama, response language, and status behavior must remain intact.
