# V0.2.26.1 Activity-Aware Timeout Hotfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Base-model streaming activity, rather than total round wall time, determine timeout after first byte, while disabling the whole-task deadline by default.

**Architecture:** Keep first-byte and post-first-byte inactivity as separate model-round phases. Retain the optional whole-task deadline as an outer bound only when explicitly configured; otherwise tools and model rounds use their existing local protections.

**Tech Stack:** Node.js 22, native test runner, Anthropic SSE activity telemetry, Docker Compose.

## Global Constraints

- Runtime release: `0.2.26.1`.
- npm metadata: `0.2.26+hotfix.1`.
- No new ENV variables.
- Do not modify Media/Vision, WebSearch, WebFetch, scheduling, or language policy.
- Preserve existing timeout error codes.
