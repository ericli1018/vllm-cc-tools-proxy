# V0.2.3 Progress Sentinel Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Remove hidden request-scoped sentinel text from Claude Code-visible SSE while preserving visible progress, next-turn history cleanup, legacy V0.2.2 cleanup, streaming, and managed response block ordering.

**Architecture:** Progress remains a dedicated first Anthropic text block. The block begins with a stable human-readable heading instead of a hidden nonce. On later requests, the proxy removes that first block structurally; it also keeps legacy cleanup for V0.2.2 sentinel-wrapped history. No model response block or normal assistant text is removed.

**Tech Stack:** Node.js 22 ESM, Anthropic Messages SSE, node:test.

## Global Constraints

- Do not emit `VLLMCCP:v1:*` in any new SSE output.
- Keep visible progress updates and SSE ping behavior.
- Keep one `message_start` and one `message_stop` per managed response.
- Preserve upstream content-block index shifting when a progress block is visible.
- Strip V0.2.2 legacy sentinel history for backward compatibility.
- Version the release as `0.2.3` and create a clean verified ZIP.
