# V0.2.28.1 GLM Output Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enforce final-language post-validation and sanitize GLM Vision reasoning before evidence delivery.

**Architecture:** Reuse the existing language classifier as the acceptance gate after every repair backend. Add a small Vision visible-content sanitizer at the Vision client boundary, and normalize GLM no-think hints per provider without altering routing or config surface.

**Tech Stack:** Node.js ESM, native node:test, Anthropic-compatible proxy contracts, Ollama `/api/chat`, OpenAI-compatible chat completions.

## Global Constraints

- Baseline: V0.2.28.
- Release: V0.2.28.1.
- No new ENV.
- No PDF/Image routing changes.
- No Managed Loop policy changes.
- Preserve native Ollama `think=false`.
- Bump visual cache to `visual-v7` and evidence cache to `evidence-v3`; keep `media-v7`.
- Final ZIP filename must be exactly `vllm-cc-tools-proxy-v0.2.28.1.zip` with no `(1)` paths.
