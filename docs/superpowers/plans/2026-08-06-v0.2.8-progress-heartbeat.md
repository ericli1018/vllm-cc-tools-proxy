# V0.2.8 File Progress and Semantic Heartbeat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show file-aware media progress in Claude Code and keep managed streams semantically active while waiting for Base vLLM.

**Architecture:** Introduce a request-scoped media progress tracker that resolves Read tool filenames and renders concise file/page status. Extend ProgressStream with visible semantic heartbeats and write telemetry, and instrument Base vLLM header/first-event timing without logging prompt contents.

**Tech Stack:** Node.js 22, Anthropic Messages SSE, native `fetch`, Node test runner.

## Global Constraints

- Preserve raw transparent bypass for unmanaged requests.
- Never expose full local paths; visible progress uses basename only.
- Keep 5-second invisible Anthropic ping and add 30-second visible text-delta heartbeat.
- Do not log document text, Base64, API keys, or full prompts.
- All production changes require failing tests first.
