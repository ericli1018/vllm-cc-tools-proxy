# V0.2.19 Managed Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden managed Claude Code/vLLM turns against malformed Laguna tool protocol output, contaminated tool evidence, repeated no-progress actions, and unbounded waits.

**Architecture:** Keep the existing transparent-bypass and managed-tool split. Strengthen only the managed boundary: sanitize untrusted history before Base submission, validate every buffered managed Base response before dispatch, perform one bounded non-thinking recovery, and terminate repeated or over-deadline work deterministically.

**Tech Stack:** Node.js 22, Anthropic Messages-compatible payloads, vLLM, Poolside Laguna S 2.1, native Node test runner.

## Global Constraints

- Release version: `0.2.19`.
- Keep ordinary Claude Code traffic transparent.
- Do not implement Anthropic-native Web Search citations/results/counts in this release.
- Preserve proxy-owned WebSearch/WebFetch execution and V0.2.18 native-response containment.
- Keep ENV simple: one managed-task timeout override only.
