# V0.2.17 Native Web Tool Normalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Normalize Anthropic native Web Search and Web Fetch server tools into vLLM-compatible custom tools while enforcing their local policies.

**Architecture:** Add one pure normalization/policy module. Apply it before all count-token and message upstream calls. Pass extracted policy into the existing managed-tool executor without changing Managed Loop response routing.

**Tech Stack:** Node.js 22, native test runner, Anthropic Messages JSON, existing SearXNG and awesome-web-fetch integrations.

## Global Constraints

- No new environment variables.
- Do not change Recovery Routing or `MAX_TOOL_ROUNDS` semantics.
- Do not forward native-only policy fields to vLLM.
- Existing custom tools and non-web tools remain byte-for-byte equivalent after normalization.
