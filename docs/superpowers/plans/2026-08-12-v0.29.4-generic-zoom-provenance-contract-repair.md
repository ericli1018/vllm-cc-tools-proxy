# v0.29.4 Generic Zoom, Provenance, and Contract Repair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure every actionable `VISUAL_STATUS: NEEDS_ZOOM` receives genuinely new visual information, preserve image origin/provenance through diagnostics/evidence, and locally repair formatting-only CONTENT contract defects without re-running Vision.

**Architecture:** Reuse the existing VisualAssetRegistry/crop pipeline and PDF tiler. Generic images get a deterministic overlapping-tile fallback only when Vision explicitly returns NEEDS_ZOOM with no crop tool call. Existing payload observation metadata is threaded through media progress/context into image diagnostics/evidence. Contract parsing distinguishes repairable marker-only defects from semantic invalidity and canonicalizes only the former.

**Tech Stack:** Node.js ESM, built-in test runner, ImageMagick-backed image normalization/cropping, existing Vision client, Media Cache, Claude Code media transform pipeline.

## Global Constraints

- Baseline: v0.29.3.
- Preserve `VLLM_VISION_THINK` exactly across retries.
- Preserve `VLLM_VISION_TIMEOUT_MS` default 120000 ms.
- Generic automatic zoom triggers only after explicit `VISUAL_STATUS: NEEDS_ZOOM` and no successful crop tool call.
- Generic image overlap: 15%; PDF schematic overlap remains 20%.
- Max zoom depth remains 2.
- Do not cache unavailable/invalid Vision evidence.
- No required new ENV variables.
- Preserve v0.29.0 Document Map / Read.pages, v0.29.1 failure isolation, v0.29.2 output contract, and v0.29.3 PDF zoom behavior.
