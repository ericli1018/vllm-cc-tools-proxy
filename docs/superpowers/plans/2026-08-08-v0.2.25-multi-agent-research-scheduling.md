# V0.2.25 Multi-Agent Research Scheduling Implementation Plan

> **For agentic workers:** execute inline with TDD; each behavior must fail before production changes.

**Goal:** Reduce Claude Code multi-agent research head-of-line blocking while making queue/model wait time truthful and bounded.

**Architecture:** Keep the general managed lane at its existing bounded concurrency. Route exclusive native WebSearch children through a separate one-slot fast lane. Gate requests with preflight input >=100000 tokens through a one-slot large-context gate before general admission. Track queue and model-round clocks separately. Add a conservative response-body stall deadline that only arms after the first upstream response byte for that model round.

**Tech Stack:** Node.js ESM, Anthropic Messages proxy, vLLM, existing ManagedQueue/Semaphore/progress infrastructure.

## Global Constraints
- Preserve v0.2.23.2 native WebSearch forced tool choice.
- Preserve v0.2.24 cumulative Base-vLLM byte accounting.
- Preserve WebFetch/Ollama processor concurrency and lifecycle.
- Add no required ENV variables.
- Native WebSearch fast lane limit: 1.
- Large-context threshold: 100000 input tokens; concurrent large contexts: 1.
- Stall detection must not start before the first upstream response byte.

### Task 1: Admission lanes
- Add native WebSearch and large-context admission lanes and health state.
- Route exclusive forced native WebSearch child requests to the fast lane.
- Gate >=100000-token general requests before general managed admission.
- Add lane/classification diagnostics.

### Task 2: Truthful progress clocks
- Queue heartbeat reports queue elapsed time and position.
- Model heartbeat starts from each actual Base model round, not request arrival.
- Preserve cumulative upstream byte display.

### Task 3: Conservative stalled-response deadline
- Track per-round first/last upstream response byte time.
- Abort only after the first byte has arrived and no additional byte arrives for the configured internal 90s stall window.
- Preserve existing managed model hard deadline.

### Task 4: Release verification
- Version 0.2.25, update docs/release notes.
- Full tests, JS syntax, verify.sh, package, fresh-unzip tests and MANIFEST verification.
