# V0.2 Simple Visual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the V0.1 sidecar deployment with one official Node.js proxy container that clones the repository at startup, performs local PDF/image preparation, delegates visual understanding to a separate OpenAI-compatible vLLM endpoint, and supports bounded model-requested crops.

**Architecture:** The proxy remains the Anthropic Messages boundary. Poppler and ImageMagick run locally through argument-array subprocesses. Images and rendered PDF pages are sent to `VLLM_VISION_URL/v1/chat/completions`; the returned Markdown replaces raw Base64 before the request is forwarded to the base Anthropic-compatible vLLM endpoint.

**Tech Stack:** Node.js 22 ESM, native `fetch`, Poppler CLI, ImageMagick CLI, Docker Compose, Node test runner.

## Global Constraints

- Use only `node:22-bookworm-slim` in Compose.
- Do not include `bootstrap.sh`, Dockerfile, git pull, parser sidecars, Redis, object storage, or persistent document handles.
- Preserve `VLLM_BASE_URL`, `VLLM_BASE_API_KEY`, `VLLM_VISION_URL`, `VLLM_VISION_MODEL`, and `VLLM_VISION_API_KEY`.
- Raw PDF/image Base64 must never reach the base vLLM.
- Visual crop requests are bounded to two rounds and validated normalized coordinates.
- Long media work must continue using Anthropic SSE progress and cancellation propagation.

### Task 1: Configuration and single-service deployment
- Replace service-mode configuration with one proxy configuration.
- Rename base and vision API-key variables.
- Replace Compose with one inline-clone service.
- Add tests proving no bootstrap, no pull, and required ENV names.

### Task 2: Local image operations and asset registry
- Add safe image metadata, normalization, crop, and resize helpers using ImageMagick.
- Add request-scoped source identifiers and bounded crop validation.
- Add tests for source lookup, normalized coordinates, and round limits.

### Task 3: Visual vLLM client and crop loop
- Send OpenAI-compatible `image_url` data URLs.
- Expose only `request_image_crop` with `parallel_tool_calls=false`.
- Execute at most two crop rounds and return Markdown plus warnings.
- Add tests for auth, tool parsing, crop feedback, and limit termination.

### Task 4: PDF batching and merged media adaptation
- Run local Poppler directly.
- Extract native text per page and render pages in batches of four.
- Send pages to visual vLLM, merge native text and visual analysis, and preserve page numbers.
- Adapt standalone images through the same visual pipeline.
- Add tests for native text fallback, scanned pages, batching, and no Base64 leakage.

### Task 5: Proxy integration, documentation, packaging, and verification

- Use separate base/vision Authorization headers.
