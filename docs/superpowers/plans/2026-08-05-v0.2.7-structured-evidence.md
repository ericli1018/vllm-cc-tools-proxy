# V0.2.7 Structured Evidence Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent PDF/Visual source text and malformed historical reasoning tags from corrupting Qwen3.6 reasoning and tool-call protocol boundaries.

**Architecture:** Replace active XML-like media wrappers with a non-XML evidence envelope whose payload is HTML-entity escaped. Inject one immutable-evidence contract into media requests, invalidate all older normalized-media cache entries, sanitize known protocol tags only inside structured assistant thinking history, and report control tags at Visual and Base-generation boundaries without rewriting Base output.

**Tech Stack:** Node.js 22, Anthropic Messages API, Ollama Native Chat API, vLLM Anthropic/OpenAI endpoints, Node test runner.

## Global Constraints

- Ordinary clean requests remain byte-transparent bypass traffic.
- Raw PDF/image Base64 must never reach Base vLLM.
- Source evidence must not contain active `<think>`, `<tool_call>`, `<function_result>`, `<tool_response>`, or ChatML tokens.
- Do not regex-delete arbitrary visible model output.
- Existing V0.2.2–V0.2.6 progress-history compatibility remains intact.
- V0.2.6 cache entries must not be reused.
