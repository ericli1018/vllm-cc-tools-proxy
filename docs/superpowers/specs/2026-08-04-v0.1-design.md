# VLLM-CC-TOOLS-PROXY V0.1 Design

## Goal

Build a deployable Claude Code compatibility proxy that accepts Anthropic Messages requests, adapts unsupported Base64 PDF/image blocks before forwarding to vLLM, optionally executes managed WebSearch/WebFetch calls, and streams truthful progress for long-running work.

## Runtime architecture

All project services run from the official `node:22-bookworm-slim` image. A mounted bootstrap script installs bounded OS dependencies, clones `https://github.com/ericli1018/vllm-cc-tools-proxy` into a named volume when absent, performs fast-forward-only `git pull` when present, and starts the selected service mode.

The same repository provides four service modes:

- `proxy`: Anthropic-compatible ingress, content adaptation, managed web-tool loop, SSE progress, vLLM forwarding.
- `document-parser`: Poppler-based PDF inspection, per-page native text extraction, raster image extraction, OCR/Vision delegation, Markdown/XML assembly.
- `image-parser`: ImageMagick-based media validation, orientation normalization, bounded resize and metadata extraction.
- `ocr-service`: Tesseract-based V0.1 OCR endpoint. External PaddleOCR-compatible services can replace it through `OCR_SERVICE_URL`.

Vision remains an external optional OpenAI-compatible endpoint selected through `VISION_SERVICE_URL` and `VISION_MODEL`.

## Request pipeline

1. Validate method, path, body size and Anthropic JSON envelope.
2. Strip proxy-generated progress sentinels from prior assistant history.
3. Walk all message content recursively, including nested `tool_result.content` arrays.
4. Decode only protocol-declared `source.type=base64` media blocks.
5. Validate decoded size, MIME and magic bytes.
6. Route PDF blocks to `DOCUMENT_PARSER_URL` and image blocks through image normalization plus OCR/Vision.
7. Replace raw Base64 blocks with bounded text blocks preserving page, parser, OCR, warning and truncation metadata.
8. Forward to vLLM. When managed WebSearch/WebFetch tools are present, use bounded non-stream internal continuations and synthesize the final Anthropic stream.
9. Abort all downstream requests on client disconnect.

## Streaming progress

For managed tasks, the proxy opens Anthropic SSE immediately, sends periodic `ping` events, creates one synthetic text block carrying request-scoped progress sentinels, appends only verified phase changes, closes that block, then emits the final model content. The next request removes only valid proxy-generated sentinel regions before forwarding history to vLLM.

Fast requests below the visible threshold receive transport pings but no visible progress noise.

## Managed tools

Aliases `WebSearch` and `web_search` map to SearXNG. `WebFetch` maps to the configured awesome-web-fetch endpoint. Results are normalized, bounded and returned internally as correlated `tool_result` blocks. A maximum of six tool rounds is enforced. Mixed managed and unmanaged tool calls are returned to Claude Code unchanged in V0.1.

## Security and limits

- No raw Base64 or full extracted content in normal logs.
- MIME and magic validation before parsing.
- Bounded body, decoded bytes, pages, image pixels, output characters, subprocess time and tool rounds.
- Temporary directories are private and removed after each request.
- Child processes use argument arrays without shell interpolation.
- Client disconnect propagates cancellation.
- Deterministic media failures return 4xx/422; transient service failures return 502/504.

## Configuration

Required:

- `VLLM_BASE_URL`

Default internal service URLs:

- `DOCUMENT_PARSER_URL=http://document-parser:8081`
- `IMAGE_PARSER_URL=http://image-parser:8082`
- `OCR_SERVICE_URL=http://ocr-service:8083`

Optional:

- `SEARXNG_URL`
- `WEB_FETCH_URL`
- `VISION_SERVICE_URL`
- `VISION_MODEL`
- `RESOURCE_PROFILE=default`
- `LOG_LEVEL=info`

Safety behavior, one internal recovery maximum, cancellation, redaction and cache keys are fixed product behavior rather than user-facing ENV switches.

## V0.1 scope

Included:

- Anthropic `/v1/messages` and health endpoints.
- PDF document block adaptation.
- JPEG/PNG/GIF/WebP image block adaptation.
- Nested tool-result media adaptation.
- Poppler native text extraction and per-page OCR fallback.
- Embedded raster image extraction, OCR and optional Vision delegation.
- SearXNG WebSearch and awesome-web-fetch WebFetch managed tools.
- SSE progress, pings, cancellation and bounded tool loop.
- Docker Compose, bootstrap clone/pull scripts, tests, documentation and ZIP packaging.

Excluded:

- Request coalescing.
- Persistent Redis/object storage.
- Native DOCX/XLSX/PPTX host-file bridge.
- Bundled large Vision model.
- Full semantic reconstruction of every vector PDF figure.
