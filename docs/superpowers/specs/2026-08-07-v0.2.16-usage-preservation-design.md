# V0.2.16 Anthropic Usage Preservation Design

## Goal

Restore accurate Anthropic input-usage signaling for streamed managed Claude Code turns without removing visible progress or changing agent/tool routing.

## Design

Before a streamed managed response opens its synthetic `message_start`, call the existing Base vLLM `/v1/messages/count_tokens` route using the sanitized incoming request. Normalize the returned token count into the downstream `message_start.usage`. Preserve final output usage from the Base response and observe Direct Streaming upstream usage without forwarding a duplicate start event.

## Failure behavior

Token counting is advisory. Abort propagation remains authoritative, but HTTP errors, unsupported endpoints, malformed count responses, and transient count failures produce a token-only warning and a zero-valued fallback. The original Claude Code turn continues unchanged.

## Boundaries

- No context truncation or summarization.
- No automatic max-token clamp.
- No new ENV.
- No changes to Managed Tool Routing or Recovery Routing.
- No prompt or tool content in usage logs.
